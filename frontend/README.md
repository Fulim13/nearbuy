# NearBuy frontend

React 19 + TypeScript + Vite, Material UI, React Router, React Hook Form + Zod, Zustand, Axios.

## Run

The backend must be up first (`make up` from the repo root; the gateway is served by the kind ingress on `http://localhost/api`).

```sh
npm install
npm run dev          # http://localhost:5173
```

Vite proxies `/api` to `http://localhost` because the gateway has no CORS. Point it elsewhere with `API_TARGET=http://host:port npm run dev`.

## Layout

```
src/
  entities/   API wire types (order ids are strings: they exceed Number.MAX_SAFE_INTEGER)
  services/   api-client (axios, big-int-safe JSON, bearer token, 401 -> logout), error messages
  stores/     authStore (zustand, persisted)
  hooks/      useData + resource hooks, useOrder (polls the 202 -> 404 -> 200 seckill flow)
  components/ NavBar, cards, forms, PrivateRoutes
  pages/      one per route (see routes.tsx)
```

## Images

Shop and profile images are plain static files served from `public/`, at the
paths the seed data already stores:

| Seeded value | Put the file at |
|---|---|
| `shop.images` = `/imgs/shops/1.jpg` … `/imgs/shops/14.jpg` | `public/imgs/shops/1.jpg` … `14.jpg` |
| `app_user.icon` = `/icons/1.png` … `/icons/3.png` | `public/icons/1.png` … `3.png` |
| admin icon `/icons/admin.png` | `public/icons/admin.png` |

The bundled shop photos are from [Unsplash](https://unsplash.com) (Unsplash
License: free to use, no attribution required) and the avatars are generated by
[DiceBear](https://www.dicebear.com)'s Lorelei style (CC0).

Missing files are fine: shops fall back to a coloured cover and avatars to the
user's initial. Shops created in the UI can point at any image URL through the
"Image URL(s)" field (the first comma-separated URL is the cover).
